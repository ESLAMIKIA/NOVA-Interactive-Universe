# NOVA — Interactive Universe

A small interactive space visualizer made with Python and Pygame.

## Run
1. Install Python 3.10+.
2. In a terminal in this folder run:

   ```bash
   pip install -r requirements.txt
   python main.py
   ```

## Controls
- **Mouse movement:** nearby stars gently gravitate toward the cursor.
- **Left click:** create a starburst of particles.
- **Space:** pause / resume.
- **Esc:** exit.

Have fun exploring!
